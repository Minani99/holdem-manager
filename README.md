# 홀덤 매니저

홈게임용 홀덤 진행 도우미입니다. 테이블 가운데 태블릿 1대를 두고 딜러가 조작하는 방식이에요.

- **블라인드 타이머**: 레벨 · 남은 시간 · 다음 블라인드 · 다음 휴식, 1분 전 경고, 레벨업 알림음과 진동, 화면 꺼짐 방지
- **핸드 진행**: 폴드 / 체크 / 콜 / 벳 · 레이즈 / 올인 버튼으로 기록하면 딜러 버튼 · 블라인드 · 행동 순서가 자동으로 진행
- **사이드팟 자동 계산**: 언더올인이 몇 명이든 메인팟 / 사이드팟을 나누고, 승자만 고르면 칩을 자동으로 분배 (스플릿, 홀수 칩, 받지 않은 베팅 반환 포함)
- **리바이 · 애드온**: 횟수와 금액 기록, 총 상금 자동 반영, 칩을 다 잃으면 리바이 / 탈락을 바로 물어봄
- **캐시 게임**: 칩과 원화를 같이 표시, 사람마다 다른 추가 바이인, 정산 후 퇴장, 손익 확인
- 모든 기록은 기기에 자동 저장돼서 앱을 닫았다 열어도 이어서 진행돼요.

## 태블릿에서 쓰는 방법

### 방법 1 — 파일 하나 보내기 (가장 간단)
`dist/holdem-manager.html` 파일을 카톡이나 USB로 갤럭시 탭에 보낸 뒤 **크롬**으로 열면 끝이에요. 인터넷이 없어도 동작해요.
(일부 기기에서는 이 방식으로 열면 '화면 꺼짐 방지'가 안 될 수 있어요. 그럴 땐 태블릿 설정에서 화면 자동 꺼짐 시간을 늘려주세요.)

### 방법 2 — 웹에 올려서 앱처럼 설치
이 폴더 전체를 GitHub Pages나 Netlify 같은 무료 호스팅에 올린 뒤, 태블릿 크롬에서 주소를 열고
**메뉴 → 홈 화면에 추가**를 누르면 전체 화면 앱처럼 설치돼요. 한 번 열고 나면 오프라인에서도 동작해요.

## 진행 순서
1. **새 게임**: 토너먼트 / 캐시 선택 → 바이인 · 칩 → 블라인드 구조(터보 / 표준 / 딥스택 프리셋, 직접 편집 가능) → 플레이어 이름 입력 → 게임 시작
2. **타이머** 탭에서 ▶ 를 눌러 블라인드 시계 시작
3. **테이블** 탭에서 `핸드 시작` → 차례인 사람의 행동을 버튼으로 입력
4. 쇼다운이 되면 팟마다 이긴 사람을 선택 → `칩 분배` → `다음 핸드`
5. 실수했으면 `되돌리기`로 한 단계씩, `핸드 취소`로 핸드 전체를 되돌릴 수 있어요.

## 개발용 명령
```bash
node tools/serve.js        # http://localhost:5173 에서 실행
node test/engine.test.js   # 베팅 · 사이드팟 계산 테스트
node tools/build.js        # dist/holdem-manager.html (파일 하나짜리) 만들기
node tools/make-icons.js   # 앱 아이콘 PNG 다시 만들기
```
