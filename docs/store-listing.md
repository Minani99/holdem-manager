# 플레이스토어 등록 문구 (초안)

## 간단한 설명 (80자 이내)
친선 홀덤 게임용 블라인드 타이머와 칩 · 사이드팟 계산기. 광고 없음, 오프라인 동작.

## 자세한 설명
친구들과 하는 친선 홀덤 게임을 진행하는 도우미예요. 테이블 가운데 태블릿 한 대만 두면 딜러가 블라인드, 차례, 칩 계산을 신경 쓰지 않아도 돼요.

■ 블라인드 타이머
· 레벨, 남은 시간, 다음 블라인드, 다음 휴식을 큰 글씨로 표시
· 1분 전 경고, 레벨업 알림음과 진동
· 게임 중 화면 꺼짐 방지
· 터보 / 표준 / 딥스택 프리셋, 직접 편집 가능

■ 핸드 진행
· 폴드 / 체크 / 콜 / 벳 · 레이즈 / 올인 버튼으로 기록
· 딜러 버튼, 블라인드, 행동 순서 자동 진행
· 되돌리기, 핸드 취소

■ 사이드팟 자동 계산
· 올인한 사람이 여러 명이어도 메인팟과 사이드팟을 자동으로 나눠요
· 이긴 사람만 고르면 칩을 자동 분배 (스플릿, 홀수 칩 포함)

■ 토너먼트 · 캐시 게임
· 리바이, 애드온, 탈락 순위 기록
· 칩과 포인트 환산, 결과 확인

■ 개인정보
· 회원가입 없음, 광고 없음, 데이터 수집 없음
· 모든 기록은 기기 안에만 저장되고 인터넷 없이 동작해요

※ 이 앱은 게임 진행을 돕는 타이머 · 계산 도구입니다. 실제 돈을 거는 도박에 사용하지 마세요. 앱 안에서 결제, 베팅, 환전 기능은 제공하지 않습니다.
